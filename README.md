# Credit Scoring Model

## Project Overview
This project predicts whether a customer is eligible for loan approval using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Logistic Regression
- Google Colab

## Dataset
The dataset contains the following features:
- Income
- Age
- Loan Amount
- Credit History
- Employment Years
- Approved

## Machine Learning Model
Logistic Regression is used to predict loan approval.

## Evaluation Metrics
The model is evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

## Result
The model successfully predicted the loan approval status.

Accuracy: 1.0  
Precision: 1.0  
Recall: 1.0  
F1-Score: 1.0  
ROC-AUC: 1.0

## Sample Prediction
New Customer: Loan Approved

## Conclusion
The Credit Scoring Model demonstrates how Machine Learning can be used to predict loan approval based on customer financial and credit-related information.
